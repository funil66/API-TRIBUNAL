1. **Instalar Dependências**
   ```bash
   # Windows
   .\setup.ps1
   
   # Linux/Mac
   ./setup.sh
   ```

2. **Configurar Ambiente**
   ```bash
   # Copiar e editar variáveis
   cp .env.example .env
   ```

3. **Executar Projeto**
   ```bash
   # Desenvolvimento
   npm run dev
   
   # Com Docker
   npm run docker:dev
   ```

4. **Acessar**
   - **Landing Page**: `fruitkha-1.0.0/index.html`
   - **API**: `http://localhost:3000`
   - **Docs**: `http://localhost:3000/docs`
